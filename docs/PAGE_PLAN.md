# Video Library System VLC — GitHub Page Plan

## 1. Purpose
- Publish a ridiculous, satire-heavy product page for the **Video Library System VLC**.
- Keep the core truth clear under the jokes: local files, VLC-powered playback, works even when internet is down.
- Frame this as a parody corporate brand (**No SaaS**, late fees, loot crates, "mega giga whale" economy).

## 2. Tone + Voice
- Aggressively overconfident "enterprise warfare" parody.
- Treat Netflix, Amazon, and Disney+ as "small mom-and-pop upstarts."
- Treat Blockbuster as the "galactic rival" in the latency war.
- Keep absurdity playful and clearly fictional.

## 3. Core Messages to Land
1. **Offline-first wins**: your media is on your own drive, so internet outages do not stop playback.
2. **Near-zero latency startup**: local files avoid network buffering drama.
3. **Simple UX**: click play, continue where you left off, or jump back slightly.
4. **VLC engine**: proven player backend, no mysterious browser player stack.
5. **Dark mode + themed UI**: practical plus meme-worthy.
6. **Loot-crate / late-fee satire loop**: humorous brand flavor for "Back Rooms" feature set.

## 4. Content Structure (for docs/index.md)
1. Hero section with brand premise and tagline.
2. "Why we exist" section (anti-SaaS parody + offline value).
3. Screenshot section (light series, dark series, movie, settings).
4. Feature section with product realities (playlist play, continue play, rewind-like resume behavior).
5. "Competitive landscape" parody callout.
6. Fake FAQ (dismissive answers about Netflix/Amazon/etc. + serious answers about VLC/local files).
7. CTA / roadmap tease (questionnaires, collectibles, banners, more satire mechanics).
